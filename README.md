Ranks the 200 protocols that have no token yet by what a token would be worth, pricing each against the market-cap-to-TVL ratio its own category already trades at, and writes a static dashboard with a farm plan per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
